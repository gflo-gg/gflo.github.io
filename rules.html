// 01 — the currency

CORES ARE NOT MONEY

Cores are virtual points for entertainment. They have zero cash value — they cannot be bought, sold, cashed out, or exchanged for anything outside this community. There is no way to purchase Cores and there never will be. You earn them by participating. That's the entire economy.
// 02 — giveaways

GIVEAWAYS ARE SEPARATE

Physical giveaways (cards, merch, anything real) are run as separate free-entry events — never bought with Cores, never gated behind spending. Cores buy chat games, influence, and virtual packs. Real prizes stay outside the economy. No exceptions, including the ones you're about to suggest.
// 03 — fair play

NO EXPLOITS

Chat earning is rate-limited — spam earns nothing but attention from the mods. Botting, alt farming, or exploiting a bug instead of reporting it gets your balance corrected to zero and logged. Find a bug? Report it. The bounty is Cores and respect. Exploit it? SEGMENTATION FAULT.
// 04 — privacy

THE LEADERBOARD & OPTING OUT

The Task Manager on this site shows the top 50 balances by display name only — the same names already shown on stream. Nothing else about you is published: no account IDs, no platform links, no history.

Want off the public board? Run !optout in chat (or ask in Discord). You keep earning and playing exactly the same — your name just stops appearing on this site from the next sync onward.
// 05 — seasons

SEASONS & RESETS

The economy runs in quarterly seasons. At season close, Core balances soft-reset — but your card collection, cosmetic roles, and a permanent prestige badge for that season survive. The grind resets. What you built doesn't.
// 06 — the fine print

SYSTEM AUTHORITY

Earning rates, game odds, and prices are tuned live to keep the economy balanced — this page and the ECONOMY page sync automatically when they change. The system reserves the right to patch, rebalance, or roll back anything, including your balance if it got there by exploit. Participation means you've read this file.
